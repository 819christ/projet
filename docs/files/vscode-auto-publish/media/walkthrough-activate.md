### Activer sur ce projet

Activez la publication en un seul clic sur le projet ouvert dans votre espace de travail :

- Le dépôt GitHub est créé automatiquement s'il n'existe pas encore.
- Le dossier `public/` avec l'index HTML de lecture seule est généré.
- Le premier commit & push est immédiatement déclenché.
- À chaque future sauvegarde de fichier, votre code est poussé automatiquement en ~3 secondes.

[Activer sur ce projet](command:autoPush.activateProject)
